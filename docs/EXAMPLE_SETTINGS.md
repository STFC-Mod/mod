Choose an example in your preferred language and save a copy as `community_patch_settings.toml`
in your [settings folder](INSTALL.md#change-settings). Back up an existing settings file before replacing it.

The English example tracks the current code. Translations may lag behind; setting names remain the same in every language.

| Language | Example settings |
| --- | --- |
| 🇬🇧 English | [English example](configuration/example_community_patch_settings_en.toml) |
| 🇩🇪 Deutsch | [Deutsches Beispiel](configuration/example_community_patch_settings_de.toml) |
| 🇳🇱 Nederlands | [Nederlands voorbeeld](configuration/example_community_patch_settings_nl.toml) |
| 🇫🇷 Français | [Exemple français](configuration/example_community_patch_settings_fr.toml) |
| 🇪🇸 Español | [Ejemplo en español](configuration/example_community_patch_settings_es.toml) |
| 🇷🇺 Русский | [Пример на русском](configuration/example_community_patch_settings_ru.toml) |
| 🇩🇰 Dansk | [Dansk eksempel](configuration/example_community_patch_settings_da.toml) |

Save your settings file to reload changes. Settings under `[patches]` require a full game restart.
